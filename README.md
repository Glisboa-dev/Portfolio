# Portfólio — Gabriel Lisboa

Site pessoal responsivo em HTML, CSS e JavaScript, em português brasileiro.

## Como executar
1. Extraia os arquivos.
2. Abra `index.html` no navegador.
3. Para desenvolvimento local, você também pode abrir a pasta no VS Code e usar a extensão Live Server.

## Antes de publicar
- Revise o texto de apresentação e os dados de contato.
- Confirme se os links de GitHub e LinkedIn estão corretos.
- Atualize as habilidades para refletir seu nível real.
- Adicione projetos à seção Projetos conforme forem concluídos.

## Publicar com GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em Build and deployment, selecione **Deploy from a branch**, escolha `main` e `/ (root)`, e salve.
